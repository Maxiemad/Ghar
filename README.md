🏠 GHAR – AI-Powered Home Design Platform

GHAR is an innovative AI-powered platform that allows users to design custom interior and exterior spaces, analyze land for safety and sustainability, and visualize their dream home in real-time 3D — all with intelligent AI assistance.

🚀 Features

🌟 Core Capabilities:
Interior Design Customization: Drag-and-drop modular furniture, lighting, wall textures, and floor plans.

Exterior Design Tools: Roof styles, smart tech integration, façade customization, and material recommendations.

AI Land Analysis: Evaluate sunlight patterns, terrain structure, and environmental risks using AI.

Live 3D Preview: See changes in real time as you update color schemes, layouts, and furniture.

AI Design Assistant: Ask questions or get smart suggestions via a ChatGPT-powered assistant.

Smart Room Suggestions: AI evaluates space usage and suggests missing elements or improvements.

Voice-Controlled Design: Navigate and design using voice commands.

Multi-language Interface: Design in your preferred language.

Connect with Professionals: Hire verified interior designers, architects, and contractors.

Shop Matching Products: Purchase items directly from the design — furniture, lighting, decor & more.

🛒 User Accounts & Cart System

Sign in using Google Auth.
View user profile on top-right after login.
Cart icon displays all added designs/products.
Checkout available through the design preview panel.
